        Guide

        Targets

        Custom API lab is a FastAPI app that grows new collections while you watch. The attacker, the defender and the loop all work here.

        VAmPI is a fixed benchmark API in a secure and a vulnerable build. Only the LLM attacker runs against it; fixes stay proposals.

        The 8 vulnerability templates

        Every collection is one of these shapes. All ask the same thing: can one user reach a resource that is not theirs?

        B1 to B7 map to OWASP API1:2023 Broken Object Level Authorization; V1 maps to API5:2023 Broken Function Level Authorization.

        Reading the lamps

        Each lamp is one collection. Waiting has not been tried yet. Probing means the attacker is trying it now. Breached (red, hatched, "!") means one user reached another's data. Fixed by defender (green, shield) is a verified fix. Secure (green outline) was never vulnerable. Unclear (amber, dashed, "?") means the check failed to run, so it is not safe. A "new" notch marks a collection added this round; "reverted" marks a fix that stopped working.

        The loop

        LLM-sampled checks

        Every collection is always checked with plain HTTP requests. Setting LLM-sampled checks above 0 also sends that many random collections to your local Ollama model; it is graded from the real responses, never from the model's say-so.

        Timing

        Deterministic checks finish in under 2 seconds. A full VAmPI run with the LLM took about 218 s on an 8 GB machine. Phase pacing slows the loop so the audience can follow it.
